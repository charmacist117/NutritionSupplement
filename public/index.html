API 연결 도움말

키 발급부터 Vercel 등록과 프로필 전환까지 순서대로 진행합니다.

기존 API 문서 API HUB 발급 Vercel 문서
신규 발급 안내 2026년 7월 31일 이후 신규 신청은 NAVER API HUB를 이용합니다. 기존 개발자센터 키는 2027년 6월 30일까지 유예 지원됩니다.
  1. 키 발급기존 키는 네이버 개발자센터, 신규 법인 키는 NAVER Cloud Platform의 NAVER API HUB에서 쇼핑인사이트 Application을 생성합니다.
  2. 환경변수 등록Vercel 프로젝트의 Settings → Environment Variables에서 아래 변수들을 Production에 등록합니다. Secret은 이 페이지에 입력하지 않습니다.
  3. 재배포환경변수는 기존 배포에 소급되지 않으므로 저장 후 Production을 Redeploy합니다.
  4. 프로필 선택배포 완료 후 이 탭에서 새로고침하고 사용할 프로필을 선택해 저장합니다.
개인 계정과 법인 계정 등록 예시

기존 개인 키

NAVER_CLIENT_ID_1=발급값
NAVER_CLIENT_SECRET_1=발급값
NAVER_CLIENT_PROVIDER_1=developers
NAVER_CLIENT_PROFILE_1=personal
NAVER_CLIENT_PROFILE_LABEL_1=개인 계정
NAVER_CLIENT_NAME_1=개인 키 1

신규 법인 API HUB 키

NAVER_CLIENT_ID_2=발급값
NAVER_CLIENT_SECRET_2=발급값
NAVER_CLIENT_PROVIDER_2=api-hub
NAVER_CLIENT_PROFILE_2=corporate
NAVER_CLIENT_PROFILE_LABEL_2=법인 계정
NAVER_CLIENT_NAME_2=법인 키 1
한 프로필에 API 키를 여러 개 연결하는 방법

같은 NAVER_CLIENT_PROFILE_n 값을 지정하면 하나의 프로필로 묶입니다. 선택한 프로필 안에서 호출 한도에 도달한 키가 있으면 다음 키로 이어서 요청합니다.

연결이 안 될 때 확인할 항목
  • Client ID와 Client Secret의 번호가 동일한지 확인
  • API HUB 키에는 NAVER_CLIENT_PROVIDER_n=api-hub가 있는지 확인
  • 환경변수 대상에 Production이 포함됐는지 확인
  • 환경변수 저장 후 새 배포가 완료됐는지 확인
  • 선택한 프로필에 등록된 키의 일일 호출 한도가 남아 있는지 확인

Vercel 환경변수 구성

NAVER_CLIENT_ID_1Client ID NAVER_CLIENT_SECRET_1Client Secret NAVER_CLIENT_PROVIDER_1기존 키: developers / API HUB 키: api-hub NAVER_CLIENT_PROFILE_1프로필 코드: personal 또는 corporate NAVER_CLIENT_PROFILE_LABEL_1표시명: 개인 계정 또는 법인 계정 NAVER_CLIENT_NAME_1키 구분명: 개인 키 1
